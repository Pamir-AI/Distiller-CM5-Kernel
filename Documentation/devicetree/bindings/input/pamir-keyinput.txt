Pamir Key Input Driver
=====================

The Pamir Key Input driver provides support for button inputs from an RP2040 
microcontroller connected via UART2 (ttyAMA2) on a Raspberry Pi Compute Module 5.

Required properties:
- compatible: Must be "pamir,key-input"

Optional properties:
- debounce-interval-ms: Debounce time for button inputs in milliseconds (default: 50ms)
- poll-interval-ms: Polling interval for button press detection in milliseconds (default: 10ms)
- raw-protocol: Boolean flag. When present, enables raw protocol mode where each byte 
                received from UART is interpreted as a button state rather than parsing
                newline-terminated ASCII numbers. Default: disabled (use line protocol).
- report-press-only: Boolean flag. When present, only button press events are reported
                     to userspace, not release events. Default: disabled (report both).
- recovery-timeout-ms: UART recovery timeout in milliseconds (default: 1000ms)

The driver interprets button state bits according to the following mapping:
- Bit 0 (0b0001): UP button
- Bit 1 (0b0010): DOWN button
- Bit 2 (0b0100): SELECT button
- Bit 3 (0b1000): POWER button (shutdown request)

Example:
========

Example of device tree entry:

serdev: serial-controller {
	compatible = "linux,serdev-controller";
	#address-cells = <1>;
	#size-cells = <0>;
	serdev-device@0 {
		compatible = "pamir,key-input";
		reg = <0>;
		status = "okay";
		debounce-interval-ms = <50>;
		poll-interval-ms = <10>;
		/* raw-protocol; */
		/* report-press-only; */
		recovery-timeout-ms = <1000>;
	};
};

Example of device tree overlay usage:
=====================================

To enable the driver using the provided overlay, add the following to your config.txt:

dtoverlay=pamir-keyinput

With custom parameters:

dtoverlay=pamir-keyinput,debounce=100,poll_interval=20,raw_protocol=1,report_press_only=1
